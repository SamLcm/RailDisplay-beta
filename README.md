# RailDisplay-beta

Werkende reconstructie van een Nederlandse NS AMF CTA Type 1.

## Testen in VS Code

1. Clone of pull deze repository.
2. Open de map in VS Code.
3. Installeer de aanbevolen extensie **Live Server**.
4. Open `index.html` en kies **Open with Live Server**.
5. Na een nieuwe GitHub-versie: voer eerst `git pull` uit en vernieuw daarna de browser.

De gegevens staan los van de renderer in `data/`. Daardoor kunnen nieuwe flapstanden worden toegevoegd zonder de CTA-layout opnieuw te bouwen.
